Polymarket Trading Bot

A beginner-friendly Python trading bot for Polymarket with gasless transactions and real-time WebSocket data.

View on GitHub

Simple API

Just a few lines of code to start trading on Polymarket prediction markets.

Gasless Transactions

No gas fees with Builder Program credentials. Trade without worrying about gas costs.

Real-time WebSocket

Live orderbook updates via WebSocket for real-time market data streaming.

15-Minute Markets

Built-in support for BTC/ETH/SOL/XRP 15-minute Up/Down markets.

Flash Crash Strategy

Pre-built strategy for volatility trading with configurable parameters.

Fully Tested

89 unit tests covering all functionality with CI/CD pipeline integration.

Quick Start

pip install -r requirements.txt
export POLY_PRIVATE_KEY=your_metamask_private_key
export POLY_SAFE_ADDRESS=0xYourPolymarketSafeAddress
python examples/quickstart.py

Trading Strategies

Flash Crash Strategy

Monitors 15-minute Up/Down markets for sudden probability drops and executes trades automatically.

python strategies/flash_crash_strategy.py --coin BTC --drop 0.30 --size 10

Options:

FlagDefaultDescription
--coinETHBTC, ETH, SOL, XRP
--drop0.30Drop threshold (absolute change)
--size5.0Trade size in USDC
--take-profit0.10Take profit in dollars
--stop-loss0.05Stop loss in dollars
